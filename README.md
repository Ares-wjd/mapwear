## 왜 필요한가

마모된 차선은 비 오는 밤처럼 시야가 나쁠 때 특히 잘 보이지 않습니다.
그런데 눈으로 하는 점검은 사람마다 판단이 달라, 여러 구간을 같은 기준으로 비교하기 어렵습니다.

MapWear는 차량에 단 카메라 영상만으로 긴 도로를 살펴보고,
차선 상태를 **같은 기준의 숫자**로 바꿔 어디부터 손봐야 할지 한눈에 보이게 합니다.

## 어떻게 동작하나

| 단계 | 하는 일 |
|:---:|---|
| **1. 사진 추출** | 주행 영상에서 약 4.6m마다 한 장씩 사진을 뽑고, 사진마다 촬영 위치를 붙입니다 |
| **2. AI 차선 검출** | YOLOv8 세그멘테이션 모델이 사진 속 차선을 **한 줄씩 따로** 찾아냅니다 |
| **3. 원근 보정** | 비스듬히 찍힌 도로를 위에서 내려다본 모습(BEV)으로 펴서 실제 거리로 잴 수 있게 합니다 |
| **4. 도색 판정** | 차선 경로를 곡선으로 복원해 **있어야 할 자리**를 만들고, **실제로 남은 도색**과 겹쳐 비교합니다 |
| **5. LCS 산출** | 4개 지표를 합쳐 0~100점의 점수와 등급을 매깁니다 |
| **6. 지도 표시** | 도로를 20m 구간으로 나누고, 구간마다 등급 색으로 지도에 그립니다 |

## LCS — Lane Condition Score

차선이 "얼마나 남았나"만 보지 않고, 끊김·노면과의 구분·밝기까지 함께 봅니다.

| 지표 | 비중 | 의미 |
|---|:---:|---|
| 면적 유지율 | 40% | 원래 칠해져 있어야 할 면적 중 실제로 남아 있는 비율 |
| 연속성 | 25% | 차선이 끊기지 않고 이어진 정도 |
| 명암비 | 20% | 노면과 얼마나 뚜렷하게 구분되는지 |
| 밝기 | 15% | 차선 자체가 얼마나 밝게 보이는지 |

```
LCS = 면적 유지율 × 0.40 + 연속성 × 0.25 + 명암비 × 0.20 + 밝기 × 0.15
```

| 등급 | 점수 |
|:---:|:---:|
| 🟢 양호 | 80 ~ 100 |
| 🟠 주의 | 60 ~ 80 |
| 🔴 위험 | 0 ~ 60 |

한 구간(20m)에는 사진이 여러 장 들어갑니다. 지표마다 사진들의 **중앙값**을 써서
한 장이 흔들려도 점수가 튀지 않게 하고, 유효 사진이 3장 미만이면 「데이터 부족」으로 둡니다.

## 사이트 기능

**소개 페이지** — 기술 단계, LCS 점수 설명, 실제 촬영 구간 지도 미리보기

**대시보드**
- 20m 구간마다 등급 색으로 칠한 지도
- 구간에 마우스를 올리면 점수 요약, 누르면 상세 정보
  (LCS · 4개 지표 · 촬영 정보 · 카카오맵에서 위치 보기)
- **점수 낮은 구간 목록** — 누르면 지도가 그 구간으로 이동
- 등급 필터 · 도로명 검색 · 초기화
- 지금 보이는 구간만 **CSV로 내려받기** (엑셀에서 한글이 깨지지 않음)
- 휴대폰 화면 지원

## 폴더 구조

```
├─ index.html          소개 페이지
├─ dashboard.html      대시보드
├─ assets/
│  ├─ config.js        설정값 (데이터 경로, 등급 색·기준, 지표 가중치, 지도 링크)
│  ├─ style.css
│  ├─ intro.js         소개 페이지 동작
│  ├─ dashboard.js     대시보드 동작
│  └─ img/             사이트 사진
└─ data/
   └─ lcs_segments_20260914.json   지도에 그리는 데이터
```

> 이 저장소에는 **웹사이트만** 들어 있습니다. 영상 분석 파이프라인(차선 검출 · 원근 보정 · 도색 판정)은 포함되어 있지 않습니다.

## 데이터 형식

촬영 한 번이 JSON 파일 하나이고, 그 안에 20m 구간이 여러 개 들어갑니다.
구간 하나는 **지도를 그리는 데 필요한 것(`map`)** 과 **눌렀을 때 보여줄 것(`detail`)** 으로 나뉩니다.

```json
{
  "schema_version": "1.2",
  "segment_count": 147,
  "segments": [
    {
      "segment_id": "SAMPLE_0001",
      "map": {
        "geometry": { "type": "LineString", "coordinates": [[128.18727, 35.16889], [128.18749, 35.16886]] },
        "lcs_grade": "주의"
      },
      "detail": {
        "road_name": "진마대로",
        "latitude": 35.1688742, "longitude": 128.187379,
        "lcs_score": 69.8,
        "area_score": 69.7, "continuity_score": 74.7, "contrast_score": 63.5, "brightness_score": 70.2,
        "frame_count": 4, "confidence": null,
        "captured_at": "2026-09-14T13:30:00.507+09:00",
        "capture_metadata": { "weather": "맑음", "day_night": "주간", "vehicle_speed": 71.0, "camera_model": "..." }
      }
    }
  ]
}
```

- `geometry` 의 좌표 순서는 GeoJSON 표준대로 **[경도, 위도]** 입니다.
- `lcs_grade` 가 `null` 이면 「데이터 부족」으로 회색 표시됩니다.

## 데이터 바꾸는 법

1. 같은 형식의 JSON 파일을 `data/` 에 넣습니다.
2. `assets/config.js` 맨 위의 `DATA_URL` 을 새 파일 이름으로 바꿉니다.
3. 점수가 실제 값이면 `SHOW_SAMPLE_NOTICE` 를 `false` 로 바꿉니다 (위쪽 안내 띠와 CSV 표시가 꺼집니다).

## 내 PC에서 실행하기

`index.html` 을 더블클릭해 열면 브라우저 보안 때문에 데이터를 읽지 못합니다. 간단한 서버로 띄웁니다.

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` 를 엽니다.
